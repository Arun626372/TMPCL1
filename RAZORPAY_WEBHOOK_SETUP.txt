TMPCL Razorpay Webhook Setup Guide
====================================

Current base used for this update:
- tmpcl_registration_slip_export_dashboard_update_root_only.zip

IMPORTANT
---------
Do NOT put Razorpay Key Secret, Webhook Secret, or SERVICE_ROLE_KEY inside HTML/JS/frontend.
They must stay in Supabase Edge Function Secrets only.

1) Run SQL update
-----------------
Supabase Dashboard -> SQL Editor -> paste/run:
- supabase-payment-webhook-update.sql

If this is a fresh database, you can run:
- supabase-schema.sql

2) Create Supabase Edge Function
--------------------------------
Function name:
razorpay-webhook

Function URL after deployment:
https://ybfrnvkikhtlouocobnk.supabase.co/functions/v1/razorpay-webhook

Use the file content from:
razorpay-webhook-index.ts

If using Supabase CLI, create this structure locally:
supabase/functions/razorpay-webhook/index.ts

Then deploy:
supabase functions deploy razorpay-webhook --no-verify-jwt

3) Set Supabase Edge Function Secrets
-------------------------------------
Supabase Dashboard -> Edge Functions -> Secrets

Add these names exactly:
RAZORPAY_KEY_ID = your Razorpay Key ID, example rzp_test_...
RAZORPAY_KEY_SECRET = your Razorpay Key Secret
RAZORPAY_WEBHOOK_SECRET = your webhook secret text
SERVICE_ROLE_KEY = your Supabase service role key

Use SERVICE_ROLE_KEY because your Supabase already uses this name.

4) Create Razorpay Webhook
--------------------------
Razorpay Dashboard -> Account & Settings -> Webhooks -> Add New Webhook

Webhook URL:
https://ybfrnvkikhtlouocobnk.supabase.co/functions/v1/razorpay-webhook

Secret:
Use the exact same value that you saved in Supabase as RAZORPAY_WEBHOOK_SECRET.

Events:
payment.captured
payment.failed
order.paid

5) How it updates Supabase
--------------------------
Webhook will update:
players.payment_status
players.razorpay_payment_id
players.razorpay_order_id
players.payment_amount
players.payment_currency
players.paid_at

It also inserts event records into:
payments

6) Important matching rule
--------------------------
For automatic player matching, Razorpay Order/Payment notes should include:
registration_id = TMPCL-xxxxxxx

If order notes are not added yet, webhook will still store payment in payments table,
but may not know which player to mark Paid. The next step after webhook is Razorpay Order creation from backend with registration_id in notes.
